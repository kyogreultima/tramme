# Packs and polish Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. In this repository the plan runs through the roadmap loop ([docs/roadmap-loop.md](../../roadmap-loop.md)): Task 0 puts it in the loop's queue, and from then on **the roadmaps' checkboxes are the state**, not this file's.

**Goal:** Land every open step of the packs roadmap (steps 3 to 17), the open boxes of the generation, shorts and sound roadmaps, and a new polish roadmap (playback tests, desktop attention, the packs' commands on the home screen, a Packs page in the docs, and a few editor improvements), each as tested, translated, changelogged work.

**Architecture:** A pack is one self-contained ES module in `plugins/<pack>.js` (no imports), listed in `plugins/index.json`, its data beside it in `plugins/<pack>/` and read at authoring time with `ctx.packFile`. Tools lay out ordinary layers. Nodes are pure functions of their props and `t`. Pure helpers are exported and tested in `apps/editor/test/packs.test.ts`. Editor work follows the module next to it: a tool in the vocabulary, a setting in `settings.ts`, a string in both locales.

**Tech Stack:** TypeScript (editor, packages), plain ES modules (packs), Preact + signals, Canvas 2D / WebGL2 (GLSL effects), Vitest, Tauri 2 (desktop), Astro + Starlight (site).

**Spec:** The behaviour of each box is written in its roadmap. This plan adds what the roadmaps leave to the implementer: order, files, names, signatures and tests.

## Global Constraints

- House rules of the loop, verbatim in force: rendering is a pure function of `t`; a model or an analysis runs at authoring time and its result is saved as an asset; every new property comes from a schema (`npm run schema` when the document format changes); every new tool is in the editor's vocabulary (`use_tool` and the `/` menu) with its `ai` notes; every interface string in English and French; no model packed in the bundle.
- Packs, from the roadmap's principles: **any film, never one video** (each pack tried on at least three inputs and in 16:9 and 9:16 before its box is ticked); colours only as token references (`@plate`, `@ink`, `@accent`, `@accent2`), curves and pace from the kit (`enter`, `exit`, `pace`, `stagger`); draw-ons of 0.4 to 0.8 s eased out; no gradients, glows or violets; seeded layouts (same input and seed give the same result).
- **One file, no imports** per pack. A need shared by two packs goes into Tramme itself or into the pack that already owns it (the walkthrough's `device` frame, the charts' `niceMax`).
- **Licences:** MIT, ISC, BSD, Apache-2.0, OFL or public domain only, each listed in `THIRD_PARTY_NOTICES.md`. Nothing CC-BY.
- **No network** for a pack, at authoring or render time. Data ships beside the pack; only what a tool used is written into the project.
- **Complete when it lands** (each pack task's last step, never skipped):
  - `ai` notes (when, avoid, an example) on every node, effect, modifier and tool;
  - French for every title, label and description (`messages.fr`);
  - `export.svg` / `export.lottie` hooks where the node can be static;
  - the pack in `plugins/index.json` (regenerated by Task 3's script) and in the README's Packs line;
  - a line in `CHANGELOG.md` under `Unreleased`;
  - the roadmap box ticked and its Status line updated.
- Commits: Conventional Commits, author `KYOGRE <aziz@kyogre.dev>`, no `Co-Authored-By`, no mention of Claude.
- Gate before every push: `npm run typecheck` and `npm test` pass. Add `npm run site:build` when a docs page changed.

## Review Focus

The inputs the roadmaps imply but no box names. Each one is pinned by a test in the task that owns the code.

1. **A project with no kit and no tokens.** Every pack tool falls back to the default tokens (`@ink` on `@plate`) instead of throwing. Pinned in each pack task's `falls back without a kit` test.
2. **9:16 layouts.** A tool laying out for 1080×1920 keeps everything inside the frame and above the legibility floor. Pinned in each pack task's `fits 9:16` test.
3. **Accents and non-Latin text.** Place search with accents (`"São Paulo"`, `"Zürich"`), code with tabs and CJK in strings, chat lines with emoji. Pinned in Tasks 4, 8 and 10.
4. **Seek order.** A frame rendered alone equals the same frame reached by playing (boil, twos, liquid, rigid bodies, scramble). Pinned by `any frame in any order` tests in Tasks 7, 13, 14 and 17.
5. **Large inputs.** A 2 000-line file, a 200-entry race CSV, a 30-minute recording or sound. Each is bounded (truncated, sampled or refused with a message that says what to do), never a frozen tab. Pinned in Tasks 4, 9, 6 and 11.

## Shared shapes (every pack task)

**Pack module.** Exports `meta` (`{ id: 'tramme/<stem>', name, version: '1.0.0', description, api: 1 }`), then `nodes`, `effects`, `modifiers`, `tools`, `checks`, `kits` as the pack needs, plus `messages` (`{ fr: { ... } }`). These are the shapes `plugins/diagram.js` and `plugins/styk.js` already use.

**A pack's tests** live in `apps/editor/test/packs.test.ts`. They do two things:
- import the module (`import * as <stem> from '../../../plugins/<stem>.js'`) and add it to `PACKS`, so the shared `describe('the packs register')` covers it;
- add one `describe('<stem>')` with its own tests.

**The two Review Focus tests, the same in every pack task with a tool:**
```ts
it('falls back without a kit', async () => {
  const doc = newProject({ name: 'T', width: 1920, height: 1080, fps: 30, duration: 6 }).doc; // no tokens, no kit
  const r = await runTool(<stem>.tools![0], doc, <minimal input>);
  expect(r.ops.length).toBeGreaterThan(0);
});
it('fits 9:16', async () => {
  const doc = newProject({ name: 'T', width: 1080, height: 1920, fps: 30, duration: 6 }).doc;
  const r = await runTool(<stem>.tools![0], doc, <typical input>);
  for (const b of boxesOf(applyOps(doc, r.ops).doc)) expect(inside(b, 1080, 1920)).toBe(true);
});
```
`runTool`, `boxesOf` and `inside` are test helpers that Task 3 adds at the top of `packs.test.ts`. Task 3 defines their signatures; every pack task uses them as defined there.

**Verification commands:**
- one pack: `npx vitest run apps/editor/test/packs.test.ts -t "<stem>"`
- everything: `npm run typecheck && npm test`

### Task 1: Playback clock as a pure, tested module

The 0.13.0 fix (a clock started at once, and a start overtaken by another or by a pause schedules nothing) has no test. This task moves that logic out of `Preview` so it can be tested.

**Files:**
- Create: `apps/editor/src/playclock.ts`
- Modify: `apps/editor/src/preview.ts` (`advance`, `play`, `stopAudio`, the `clock` and `playRun` fields)
- Test: `apps/editor/test/playclock.test.ts`

**Interfaces:**
- Produces:
  - `export interface Clock { at: number; t0: number; audio: boolean }`
  - `export function clockTime(c: Clock, now: number): number`, which returns `c.t0 + (now - c.at)`.
  - `export function step(c: Clock, now: number, duration: number, loop: boolean): { t: number; wrap: boolean; end: boolean }`, where `wrap` means "start again from `t`" and `end` means "stop at `duration`".
  - `export class Runs { begin(): number; cancel(): void; live(run: number): boolean }`. `begin` cancels the run before it and returns a new id. `live` is true only for the latest id that has not been cancelled.

- [ ] **Step 1: Write the failing tests.**
  ```ts
  it('reads the clock from its start', () => expect(clockTime({ at: 10, t0: 2, audio: false }, 11.5)).toBe(3.5));
  it('wraps a loop once, at the remainder', () => expect(step({ at: 0, t0: 9, audio: false }, 2, 10, true)).toEqual({ t: 1, wrap: true, end: false }));
  it('ends without a loop', () => expect(step({ at: 0, t0: 9, audio: false }, 2, 10, false)).toEqual({ t: 10, wrap: false, end: true }));
  it('a restarted clock no longer wraps', () => {
    const now = 100, restarted: Clock = { at: now, t0: 0, audio: false };
    expect(step(restarted, now + 0.016, 10, true).wrap).toBe(false);
  });
  it('a run overtaken by another is dead', () => { const r = new Runs(); const a = r.begin(); const b = r.begin(); expect(r.live(a)).toBe(false); expect(r.live(b)).toBe(true); });
  it('a pause kills the run under way', () => { const r = new Runs(); const a = r.begin(); r.cancel(); expect(r.live(a)).toBe(false); });
  ```
- [ ] **Step 2: Run them.** `npx vitest run apps/editor/test/playclock.test.ts`. Expected: FAIL (module missing).
